## 🌟 Что это за проект?

Это **веб-сайт университета IITU** (Международный Университет Информационных Технологий).

### Что есть на сайте:
- ✅ Регистрация и вход для студентов
- ✅ Главная страница с информацией об университете
- ✅ Чат для общения студентов
- ✅ Административная панель для управления
- ✅ Страницы о программах, поступлении, контактах

### Технологии:
- **PHP** - серверная часть (обработка данных)
- **MySQL** - база данных (хранение информации)
- **HTML** - структура страниц
- **CSS** - дизайн и стили
- **JavaScript** - интерактивность

## 💾 Что нужно установить?

### 1. Visual Studio Code (VS Code)
Это **редактор кода** - программа для написания и редактирования кода.

**Скачать:** https://code.visualstudio.com/

**Установка Windows:**
1. Скачайте файл `VSCodeSetup.exe`
2. Запустите установщик
3. Нажимайте "Далее"
4. ✅ ВАЖНО: Поставьте галочку "Add to PATH"
5. Нажмите "Установить"

### 2. XAMPP
Это **пакет программ** для запуска сайта локально на вашем компьютере.

**Что включает:**
- Apache - веб-сервер
- MySQL - база данных
- PHP - язык программирования

**Скачать:** https://www.apachefriends.org/

**Установка Windows:**
1. Скачайте файл установки
2. Запустите от имени администратора
3. Выберите компоненты: Apache, MySQL, PHP
4. Установите в `C:\xampp`
5. Дождитесь завершения

**После установки:**
1. Найдите ярлык "XAMPP Control Panel"
2. Запустите его
3. Нажмите "Start" напротив Apache
4. Нажмите "Start" напротив MySQL
5. Они должны стать зелеными

### 3. Браузер
Любой современный браузер:
- Google Chrome (рекомендуется)
- Mozilla Firefox
- Microsoft Edge

## 📝 Пошаговая инструкция

### Шаг 1: Подготовка проекта

#### Вариант A: Если проект уже скачан
1. Откройте папку с проектом
2. Скопируйте всю папку проекта
3. Вставьте в `C:\xampp\htdocs\`
4. Переименуйте папку в `iitu-project`

#### Вариант B: Если проект на GitHub
1. Откройте командную строку (Win+R, введите `cmd`)
2. Введите:
```bash
cd C:\xampp\htdocs
git clone <ссылка-на-репозиторий> iitu-project
```

### Шаг 2: Создание базы данных

1. **Откройте браузер**
2. **Перейдите:** http://localhost/phpmyadmin
3. **Нажмите "Создать базу данных" (New)**
4. **Введите имя:** `group_project_web`
5. **Выберите кодировку:** `utf8mb4_general_ci`
6. **Нажмите "Создать" (Create)**

### Шаг 3: Импорт таблиц

1. **Выберите базу данных** `group_project_web` (слева)
2. **Перейдите на вкладку "SQL"**
3. **Откройте файл** `database_setup.sql` из проекта
4. **Скопируйте весь код** из файла
5. **Вставьте в поле SQL**
6. **Нажмите "Вперёд" (Go)**
7. **Должно появиться:** "Запрос выполнен успешно"

### Шаг 4: Открытие проекта в VS Code

1. **Запустите VS Code**
2. **Нажмите:** File → Open Folder (или Ctrl+K Ctrl+O)
3. **Выберите папку:** `C:\xampp\htdocs\iitu-project`
4. **Нажмите "Выбрать папку"**

### Шаг 5: Установка расширений VS Code

VS Code покажет уведомление: "This workspace has extension recommendations"

**Нажмите "Install All"** - это установит нужные расширения.

**Или установите вручную:**
1. Нажмите `Ctrl+Shift+X` (открыть Extensions)
2. Найдите и установите каждое:
   - **PHP Intelephense** - подсказки для PHP
   - **PHP Debug** - отладка PHP
   - **Live Server** - просмотр сайта
   - **HTML CSS Support** - подсказки для HTML/CSS
   - **Auto Rename Tag** - автоматическое изменение тегов
   - **Auto Close Tag** - автоматическое закрытие тегов

### Шаг 6: Проверка работы

1. **Убедитесь что XAMPP запущен:**
   - Откройте XAMPP Control Panel
   - Apache должен быть зелёным
   - MySQL должен быть зелёным

2. **Откройте браузер:**
   ```
   http://localhost/iitu-project/auth.html
   ```

3. **Должна открыться страница входа/регистрации**

## 🖥️ Работа в VS Code

### Интерфейс VS Code

```
┌─────────────────────────────────────────────────┐
│  File  Edit  View  ...                    [?] X │ ← Меню
├──────┬──────────────────────────────────────────┤
│ 📁   │  Код файла                                │
│ 🔍   │  (здесь вы редактируете код)             │
│ 🐛   │                                           │
│ ⚙️   │                                           │
└──────┴──────────────────────────────────────────┘
   ↑
   Боковая панель
```

### Основные зоны:

1. **Боковая панель (слева):**
   - 📁 **Explorer** - список файлов проекта
   - 🔍 **Search** - поиск по файлам
   - 🌿 **Source Control** - Git (управление версиями)
   - 🐛 **Debug** - отладка
   - 🧩 **Extensions** - расширения

2. **Центр:** код файла
3. **Внизу:** терминал (консоль)

### Открытие файлов

**Способ 1: Через Explorer**
1. Нажмите на иконку 📁 (Explorer)
2. Выберите файл из списка
3. Файл откроется в центре

**Способ 2: Быстрый поиск**
1. Нажмите `Ctrl+P`
2. Начните вводить имя файла
3. Выберите нужный файл из списка

### Полезные горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl+P` | Быстрый поиск файла |
| `Ctrl+Shift+F` | Поиск по всем файлам |
| `Ctrl+S` | Сохранить файл |
| `Ctrl+F` | Найти в файле |
| `Ctrl+H` | Найти и заменить |
| `Ctrl+/` | Закомментировать строку |
| `Alt+↑/↓` | Переместить строку |
| `Ctrl+D` | Выделить следующее совпадение |
| `Ctrl+`` | Открыть/закрыть терминал |
| `F5` | Запустить отладку |

### Работа с терминалом

1. **Открыть терминал:** `Ctrl+`` (буква ё)
2. **В терминале можно:**
   - Запустить PHP сервер
   - Проверить код
   - Выполнять команды

**Полезные команды:**
```bash
# Проверить версию PHP
php -v

# Запустить встроенный PHP сервер
php -S localhost:8000

# Проверить синтаксис файла
php -l filename.php
```

## 🎨 Как изменить сайт

### 1. Изменить текст на странице

**Пример: Изменить заголовок на главной странице**

1. Откройте файл `index.php`
2. Найдите строку (Ctrl+F): `<h2>Shaping the Future of Technology</h2>`
3. Измените текст между `<h2>` и `</h2>`
4. Сохраните (Ctrl+S)
5. Обновите страницу в браузере (F5)

### 2. Изменить цвета и дизайн

**Пример: Изменить цвет шапки сайта**

1. Откройте файл `header.css`
2. Найдите `.header { ... }`
3. Измените `background-color: #значение;`
4. Сохраните
5. Обновите страницу

**Примеры цветов:**
- `#ff0000` - красный
- `#00ff00` - зелёный
- `#0000ff` - синий
- `#000000` - чёрный
- `#ffffff` - белый

### 3. Добавить новую страницу

**Шаг 1: Создать HTML файл**
1. Правый клик в Explorer → New File
2. Имя: `new_page.html`
3. Добавьте код:

```html
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Новая страница</title>
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>Это новая страница!</h1>
    <p>Здесь ваш контент</p>
</body>
</html>
```

**Шаг 2: Добавить ссылку в меню**
1. Откройте `header.html`
2. Найдите `<ul>` список
3. Добавьте:
```html
<li><a href="new_page.html">Новая страница</a></li>
```

### 4. Изменить изображения

1. Поместите новое изображение в папку проекта
2. Откройте нужный файл (например `index.php`)
3. Найдите `<img src="старое_фото.jpg">`
4. Замените на `<img src="новое_фото.jpg">`

## ❓ Что делать если не работает

### Проблема 1: "Connection failed" при открытии сайта

**Причина:** База данных не подключена

**Решение:**
1. Откройте XAMPP Control Panel
2. Убедитесь что MySQL запущен (зелёный)
3. Если не запущен - нажмите Start
4. Перезагрузите страницу в браузере

### Проблема 2: PHP код отображается как текст

**Причина:** Файл открыт не через сервер

**Неправильно:** `file:///C:/xampp/htdocs/...`
**Правильно:** `http://localhost/...`

**Решение:**
1. Убедитесь что Apache запущен в XAMPP
2. Открывайте через `http://localhost/iitu-project/...`

### Проблема 3: "Database not found"

**Причина:** База данных не создана

**Решение:**
1. Откройте http://localhost/phpmyadmin
2. Создайте базу данных `group_project_web`
3. Импортируйте `database_setup.sql`

### Проблема 4: Страница белая или ошибка 404

**Причина:** Неправильный путь к файлу

**Решение:**
1. Проверьте правильность URL
2. Убедитесь что файл существует
3. Проверьте регистр букв в имени файла

### Проблема 5: Изменения не отображаются

**Причина:** Кэш браузера

**Решение:**
1. Нажмите `Ctrl+Shift+R` (жёсткая перезагрузка)
2. Или `Ctrl+F5`
3. Или очистите кэш браузера

### Проблема 6: VS Code не показывает подсказки для PHP

**Причина:** Расширение не установлено

**Решение:**
1. Откройте Extensions (Ctrl+Shift+X)
2. Найдите "PHP Intelephense"
3. Нажмите Install
4. Перезапустите VS Code

## 🚀 Запуск проекта

### Метод 1: Через XAMPP (рекомендуется)

1. **Запустите XAMPP Control Panel**
2. **Запустите Apache** (нажмите Start)
3. **Запустите MySQL** (нажмите Start)
4. **Откройте браузер:**
   ```
   http://localhost/iitu-project/auth.html
   ```

### Метод 2: Встроенный PHP сервер

1. **В VS Code откройте терминал** (Ctrl+`)
2. **Введите команду:**
   ```bash
   php -S localhost:8000
   ```
3. **Откройте браузер:**
   ```
   http://localhost:8000/auth.html
   ```

### Метод 3: Через VS Code задачи

1. **Нажмите** `Ctrl+Shift+P`
2. **Введите:** "Tasks: Run Task"
3. **Выберите:** "Start PHP Server"
4. **Откройте:** http://localhost:8000/auth.html
