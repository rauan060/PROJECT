# IITU University Website Project

## 📖 О Проекте / About

This is a comprehensive website project for the International Information Technology University (IITU), designed with inspiration from the real university. The project includes student authentication, administrative dashboard, chat system, and informational pages.

Это комплексный веб-проект для Международного Университета Информационных Технологий (IITU). Проект включает систему аутентификации студентов, административную панель, чат и информационные страницы.

## ✨ Особенности / Features

- 🔐 Student authentication and registration system
- 💬 Real-time chat for students
- 👨‍💼 Administrative dashboard for managing students
- 📱 Responsive design
- 🎓 Information about university programs, admissions, and contacts
- 🔒 Session management and security

## 🛠️ Технологии / Technologies

- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP 7.4+
- **Database:** MySQL 5.7+
- **Server:** Apache (XAMPP/WAMP/LAMP)

## 🚀 Быстрый Старт / Quick Start

### Для начала работы / To get started:

1. **Клонируйте проект / Clone the project:**
   ```bash
   git clone <repository-url>
   cd PROJECT
   ```

2. **Настройте окружение / Setup environment:**
   - Install XAMPP/WAMP/LAMP
   - Start Apache and MySQL services

3. **Создайте базу данных / Create database:**
   - Open phpMyAdmin (http://localhost/phpmyadmin)
   - Create database: `group_project_web`
   - Import SQL tables or create manually

4. **Откройте в браузере / Open in browser:**
   ```
   http://localhost/PROJECT/auth.html
   ```
