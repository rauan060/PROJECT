### 6. **.vscode/** папка (Настройки VS Code)

Эта папка содержит настройки для VS Code, которые автоматически настроят вашу рабочую среду!

#### 6.1 **settings.json** (Настройки рабочей области)
**Что делает:**
- Настраивает форматирование кода
- Включает автодополнение для PHP
- Настраивает табуляцию и отступы
- Включает Emmet для PHP

#### 6.2 **extensions.json** (Рекомендуемые расширения)
**Что делает:**
- VS Code автоматически предложит установить нужные расширения
- Вы увидите уведомление "Install recommended extensions"

**Включённые расширения:**
- PHP Intelephense - подсказки для PHP
- PHP Debug - отладка
- Live Server - запуск сервера
- HTML CSS Support - подсказки HTML/CSS
- Auto Rename/Close Tag - автоматические теги
- Prettier - форматирование кода

#### 6.3 **launch.json** (Конфигурация отладки)
**Что делает:**
- Настраивает отладчик PHP
- Позволяет ставить точки останова (breakpoints)
- Запускает встроенный PHP сервер

**Как использовать:**
- Нажмите F5 в VS Code
- Выберите конфигурацию отладки
- Отладчик запустится!

#### 6.4 **tasks.json** (Задачи для VS Code)
**Что делает:**
- Добавляет быстрые команды в VS Code
- Можно запустить PHP сервер одной кнопкой
- Проверить синтаксис кода

**Доступные задачи:**
1. "Start PHP Server" - запуск сервера
2. "Check PHP Syntax" - проверка синтаксиса
3. "Open in Browser" - открыть в браузере

**Как использовать:**
- Нажмите `Ctrl+Shift+P`
- Введите "Tasks: Run Task"
- Выберите нужную задачу
